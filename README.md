# weather-app
🌤️ **Weatherly – Weather Report Application**

Weatherly is a responsive weather application built using React.js, Axios, and WeatherAPI. It allows users to search for any city and view real-time weather information.

**Features:**
- Search weather by city name.
- Display real-time temperature.
- Show weather conditions and icons.
- Display humidity and wind speed.
- Show feels-like temperature and UV index.
- Error handling for invalid city names.
- Responsive design for desktop and mobile devices.
- Modern Lavender and Purple UI design.

**Technologies Used:** React.js, JavaScript, Axios, CSS, WeatherAPI.

**Project Type:** Frontend Web Development
